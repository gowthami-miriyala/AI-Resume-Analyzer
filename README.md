# AI-Resume-Analyzer
AI Resume Analyzer – Project Description

AI Resume Analyzer is an AI-powered web application that analyzes resumes against a given job description and provides useful insights for job seekers. The system extracts important information from the resume and compares the candidate’s skills, education, experience, projects, certifications, and keywords with the requirements of the job.

Key Features
📄 Upload PDF/DOCX resumes
📋 Upload or paste a Job Description
🤖 AI-based resume analysis
📊 ATS Score (0–100)
🔍 Skills match and missing skills
🏷️ Important keyword identification
🎓 Education and qualification analysis
💼 Experience and project analysis
📜 Certification analysis
💡 Suggestions to improve the resume
💬 AI chatbot for resume and career-related questions
Technologies Used

Frontend: HTML, CSS, JavaScript
Backend: Python, Flask
AI: OpenAI API / LLM
Libraries: PyPDF, python-docx, Requests
Database: SQLite/MySQL (if implemented)
